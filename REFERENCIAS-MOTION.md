# Referências de motion — pesquisa (novembro de 2026)

**Como foi feita.** Cada site foi lido de duas formas: leitura do HTML e, para os
que só carregam com JavaScript, abertura num navegador headless (Chromium), com
captura de tela e do texto renderizado. **Não foi possível assistir aos vídeos**
(os trabalhos de motion são quase todos vídeo). Por isso, cada linha separa o
que estava **escrito ou visível na página** do que é **leitura nossa**. Nada
abaixo descreve um movimento que não tenha sido visto ou lido.

Separação pedida no briefing: **B** = motion para marca, **I** = motion para interface/produto.

## TikTok e Tinder (referências de comportamento)

Não se copiou nenhuma interface. O que se aproveitou:
- **TikTok:** a troca de conteúdo é uma **sobreposição contínua**, e a nova camada cobre a anterior. Daí a página nova chegar *por cima*, recortada pelo arco, enquanto a anterior só recua.
- **Tinder:** o **eixo horizontal tem significado** (um lado é seguir, o outro é voltar). Daí o espelhamento: avançar = arco vindo da direita; voltar = arco vindo da esquerda; na vitrine de destinos, a foto nova entra pelo lado da direção escolhida.
